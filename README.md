# ✅ Daily ToDo App

A simple and user-friendly **Daily ToDo Application** built with **React** and **TypeScript**. This app helps users manage their daily tasks efficiently with a clean and responsive interface.

Live Demo: [https://bitashamsafar.github.io/Daily-ToDo-app/](https://bitashamsafar.github.io/Daily-ToDo-app/)

---

## 📌 Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and clean UI
* Responsive design
* Fast and lightweight
* Built with modern React and TypeScript

---

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/bitashamsafar/Daily-ToDo-app.git
cd Daily-ToDo-app
```

---

### 2️⃣ Install Dependencies


```bash
yarn install
```

---

### 3️⃣ Run the Application Locally

```bash
yarn start
```

The app will run at:

```
http://localhost:3000
```
